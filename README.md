# SIM-Barang (Sistem Pengelolaan Inventaris Barang Jurusan)

Repositori ini dibuat untuk menyelesaikan tugas praktikum mata kuliah **Praktikum Pemrograman Web** Program Studi D3 Manajemen Informatika - Politeknik Negeri Sriwijaya[cite: 1].

## 1. Ringkasan Konsep HTTP Request & Response
* **HTTP Request (Permintaan):** Pesan yang dikirimkan oleh klien (seperti *browser* web) kepada server untuk meminta akses ke suatu halaman web atau sumber daya tertentu. Di dalamnya memuat metode seperti `GET` (mengambil data) atau `POST` (mengirim data).
* **HTTP Response (Respons):** Pesan balasan yang dikirimkan oleh server kembali ke klien setelah memproses permintaan tersebut. Respon ini berisi status kode (misalnya `200 OK` atau `404 Not Found`) serta data atau dokumen HTML/PHP yang ditampilkan ke layar pengguna.

## 2. Gambaran Umum Proyek SIM-Barang
**SIM-Barang** adalah sistem yang dirancang untuk mensimulasikan pencatatan, pengelolaan, dan pemantauan sarana serta prasarana (aset/barang) laboratorium dan jurusan secara terintegrasi[cite: 1]. Pengembangan aplikasi ini dilakukan secara bertahap (inkremental) dari Pertemuan 1 hingga Pertemuan 7, mulai dari penyiapan lingkungan kerja, antarmuka HTML/CSS, validasi JavaScript, hingga pemrosesan backend PHP dan basis data MySQL[cite: 1].
